## 🧀 Overview

This repository contains the official modern digital web platform for **Easy Cheesy Kasur**. Built from the ground up to convert visitors into orders with live WhatsApp messaging, interactive cart, responsive A-to-Z digital menu (105+ items across 14 categories), authentic in-house photography, and real verified customer reviews.

### Key Highlights
- **Authentic Photography & Food Varieties:** Includes high-resolution imagery for all varieties: smash burgers, crown-crust pizzas, club sandwiches, injected broast, loaded fries, dynamite wings, wraps, and authentic Chinese cuisine.
- **Complete A to Z Digital Menu:** 105+ items extracted and categorized with interactive multi-size selectors (Small, Medium, Large, Bowls, Cups) and instant search filtering.
- **Exclusive Combo Deals:** Real promotional combos formatted into cards with instant WhatsApp and cart ordering.
- **Rich Social Sharing Cards:** OpenGraph and Twitter cards featuring appetizing food photography when shared on WhatsApp, Facebook, iMessage, and Twitter.
- **Family Hall & Kids Play Zone:** Highlighting Easy Cheesy's 2-floor dining hall with the upper-floor kids inflatable play castle.
- **Mobile-First Experience (375px+):** Touch-friendly buttons (≥ 44px), sticky bottom quick-action bar (Call / WhatsApp / Cart), and smooth category filters.
- **Lighthouse Ready:** Built with semantic HTML, rich JSON-LD FastFoodRestaurant schema, next/image with blur placeholders, and accessibility focus states.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript 5 (Strict Mode)
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer
- **Motion:** Framer Motion + Tailwind Keyframe Animations
- **Icons:** `lucide-react` (100% SVG vectors)
- **Typography:** `Bebas Neue` (Display), `Plus Jakarta Sans` (Body & UI) via `next/font/google`
- **SEO:** Metadata API, OpenGraph, Twitter Cards, Sitemap, Robots, JSON-LD Schema

## 💻 Getting Started

### Prerequisites
- Node.js 18.17+ or 20+
- npm, pnpm, or yarn

### Installation & Run

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev
# Open http://localhost:3000

# 3. Production build
npm run build
```
